# SanctumCare

> A trauma-informed, zero-knowledge crisis support and wellbeing check-in platform featuring survivor privacy isolation, counselor clinical triage, and regional administrative oversight.

## ✨ Features
- **Zero-Knowledge Privacy:** Ephemeral client-side encryption with instantaneous emergency quick-exit (ESC key).
- **Guided AI Companion Check-Ins:** Empathetic, conversational check-in triage and somatic grounding exercises.
- **Counselor Portal & Real-Time Alerts:** Clinical case review, risk threshold monitoring, and escalation feeds.
- **District Administration:** Regional anonymized metrics, counselor capacity oversight, and compliance auditing.
- **Sleek Trauma-Informed UI:** Calming aesthetics with responsive left-side pop-in navigation drawer.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
1. Install dependencies:
   `ash
   npm install
   `
2. Set your environment variables in .env.local:
   `env
   GEMINI_API_KEY=your-gemini-api-key
   `
3. Start the development server:
   `ash
   npm run dev
   `
   Open [http://localhost:3000](http://localhost:3000) in your browser.
